# Checked cold TX/amplifier retirement source

This source is a prerequisite for a later opt-in diagnostic image. It is not registered at startup or called by any production UI/task, and this PR builds no diagnostic firmware image. Physical FlushOutput and production PTT remain disabled.

`CoreS3AudioCodec::MuseColdOutputOnly()` obtains one program-lifetime, IO-free instance. The one explicit `MuseColdInitialize(original_lease, config)` call copies the exact lease and configuration before callbacks. It binds common Muse custody before SDK calls. Invalid/unowned/wrong-purpose inputs reject before consuming an attempt; every admitted SDK attempt is single-use, including failures.

The native caller must supply the actual board-owned I2C bus; this API only checks a non-null handle and does not attest its hardware identity.

The cold path allocates only a TX channel, initializes STD at 24kHz with **all I2S GPIO signals unused** (including shared microphone MCLK), verifies TX/STD/disabled/bounded DMA, creates AW88298 control/GPIO/codec interfaces at the fixed CoreS3 `AW88298_CODEC_DEFAULT_ADDR` (7-bit address `0x36`, shifted SDK configuration `0x6c`; no caller-selected address) and performs checked mute/disable/register readback. It never allocates, initializes or enables RX, constructs/configures ES7210, creates esp_codec_dev data/input/output handles, registers a Core TX-sent callback, enables TX, opens PCM, starts a worker, accesses credentials or starts networking. The pinned STD initializer allocates its internal DMA interrupt machinery and enables internal peripheral clocks; this API routes no I2S clock/data pin and does not start a TX/RX channel. Pinned source: ESP-IDF v5.5.4 and esp_codec_dev1.5.4 (same drivers as the existing checked amplifier boundary).

This first interface is **retirement-only**. Legacy Start is a no-op on the cold instance (avoiding its normal saved-volume NVS read); normal Start delegates unchanged to the base. All input/output enable, PCM, SetOutputVolume, USB and rebinding entrypoints refuse on the cold instance, before initialization and after common custody release too. No stopped-DMA preload occurs during initialization. The AW88298 factory itself configures registers before checked quiet; this is not proof of prior or current acoustic silence. It is not a playback/test-tone implementation or consent for one.

## Source absence is a distinct proof

A completed cold initializer can establish original-lease-bound `input_never_created`: RX and every input/data interface remain absent, input was never enabled, and that exact common lease is still held. It never sets `direct_input_stopped_` or `direct_input_closed_`. The cold output has also never been enabled or opened. Its stop path checks actual TX info for the same handle, disabled STD state and unchanged DMA capacity; attempt bit4 means info query, not disable/close. It sets neither normal output stop nor close flag.

Existing checked retirement/discard/release accept these distinct private source proofs, while normal construction still requires its original actual stop/close flags. Reports expose `input-never-created`/`output-never-started` alongside raw stage/status and historical evidence. INVALID_STATE from a normal disable remains a failure. A disabled arbitrary channel does not acquire cold source proof.

Every initialization factory/status/info/amplifier failure retains resources and revokes the exact original lease; no partial instance is deleted, reinitialized or automatically cleaned up. A null factory return has a distinct NoObject fault, not an invented low-level error code; lower SDK status and amplifier callbacks preserve the actual code they expose. Binding loss never revokes or operates on a successor lease. Successful hardware retirement still does not release the logical lease: the original owner separately owes checked cleanup/any joins. A partial preload or failed retirement remains retained and cannot replay.

The singleton intentionally retains its bounded resources for program lifetime. It is not returned as an owning/deleteable pointer, and must not be destroyed or republished as Board's normal codec. No reset/recovery path is added. A fresh diagnostic boot with exclusive I2S ownership is required for a later harness: if normal Board audio already owns I2S0, allocation must fail and retain, not reuse its RX or steal its handles.

## Qualification and next source boundary

Production-body fault tests use inert SDK ports; they exercise the actual cold constructor, initializer and retirement methods, not a replacement initialization state machine. Cover null/partial allocation, exact failures, malformed info, no-RX/no-PCM invariants, reentry, simultaneous initialization, lease/configuration alias changes, original revocation, failure retention and legacy entry after release. Existing normal binding/amplifier/UI tests remain applicable. These are source tests, not evidence of hardware, acoustic silence, heap/stack margin or a live provider.

Before a hardware handoff, a later source slice must add an opt-in, default-off, diagnostic-only startup/view and deliberate registered local invocation, exclude normal provider/network startup, and retain the original owner/report through its bounded operation. This cold interface can exercise register/stopped-DMA retirement without microphone or playback. An audible stimulus needs a separately reviewed bounded output activation/volume contract; it must not bypass this retirement-only guard. Then link/review an exact image, measure size/config/dependencies and preserve installed/recovery artifacts. Installation/reset, invocation, output stimulus and any external measurement each require their exact attended scope. No such action occurs here.
