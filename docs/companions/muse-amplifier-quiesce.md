# Checked Muse amplifier retirement boundary

`CoreS3AudioCodec::MuseQuiesceForRetirementChecked(original_lease, ticket)` is an explicit terminal cleanup API, not a live-route registration, permission issuer, playback flush or recovery operation. No runtime caller is added. It borrows the same initialized board codec and exact held Muse/push-to-talk lease; cleanup may shut down its already revoked lease. It never authorizes microphone/output, releases common custody, joins SDK/UI workers or enables PTT.

## Existing pinned source reused

Interface and register policy come from Espressif `esp_codec_dev`1.5.4 (Apache-2.0), [esp-adf commit fcce23e3d5ecf7ba75ce9f4e3761489dc9e0299e](https://github.com/espressif/esp-adf/tree/fcce23e3d5ecf7ba75ce9f4e3761489dc9e0299e/components/esp_codec_dev). The actual firmware dependency remains unchanged. `muse_aw88298_quiet.hpp` adapts AW88298's SYSCTRL(0x04) shutdown bits0/1 and I2S-enable bit6, and SYSCTRL2(0x05) mute bit4. No external artwork, binary or new library is imported. Host stubs model only the callback shape; actual ESP32 compilation uses the pinned real interface.

The pinned high-level mute/close wrappers discard lower callback failures, and mute getters report cached state. Low-level enable(false) may return immediately when its cache is already false even though fresh register state needs shutdown. The adapter therefore uses checked get_reg/set_reg read-modify-write to preserve unrelated bits and explicitly set mute/shutdown, calls checked enable(false) to synchronize the driver's cache, then freshly verifies both control registers. It does not change the high-level mute cache; a later distinct owner's normal open retains its existing mute/volume policy.

## Evidence and ownership

The original IO mutex serializes the whole operation. The opaque original AudioLease value is captured before callbacks, so a caller reassigning its handle cannot retarget a later stop to a successor. It parks the binding before IO, revokes live audio use, mutes/disables the amplifier, checks both-direction stops, overwrites bounded stopped TX DMA and rechecks the amplifier. Raw callback status, attempted stage, observed registers, stop-call attempts/status and DMA requested/loaded/status/info are returned separately. Zero status with a readback mismatch is failure, not success. These are callback return codes, not reconstructed hidden internal transaction codes.

`RegistersAndStoppedDma` means those register and digital-memory observations only. It does not attest DAC/amp FIFO reset, acoustic silence, bounded physical interruption, hardware input latency or future restart safety. Both directions remain parked: enable/PCM/volume writes are refused until checked retirement plus the original owner's common-lease release. This prevents RX format setup from restarting paired TX behind the evidence. It is deliberately unsuitable as in-session FlushOutput; physical capability remains false.

A binding allows one quiesce attempt. Missing interfaces, wrong/old/foreign leases, zero tickets, prior discard, active scoped IO/stop/volume callbacks, reentry or a second request do no IO. Admission rejects an operation already on the stack as well as callbacks entered during quiesce; an outer enable cannot resume after a terminal receipt. Scoped IO markers restore their previous value, including nested enable/PCM calls, rather than clearing an outer operation. Once attempted, failures revoke but retain custody; apparently successful ordinary stop/close cannot clear that retention. No uncertain I2C/preload write is retried. Partial preload can advance its cursor without an exposed qualified reset API; recovery needs a separately designed and authorized fresh hardware state. Failed evidence must not be discarded by retiring the original objects. Original worker/transport/UI cleanup and common-lease release remain the caller's obligations.

The shared stop implementation has optional error/custody outputs only; existing USB/Mira/Stock call behavior is retained. The legacy volume setter now takes the same recursive IO mutex and refuses writes only while this terminal Muse park is active, restoring normal behavior after checked release. No stock/provider entrypoint, audio service, profile, partition, trust or asset is replaced.

## Qualification and remaining device work

Source fixtures run 57 cases compiling the actual production adapter/Core bodies with inert I2C/I2S/codec ports. Each retained failure runs in its own fixture process; process exit is test teardown, never a production recovery receipt. Coverage includes cached disable, positive/negative callback errors at every stage, readback mismatch, stop/close failure, partial/error preload, unexpected paired TX activity, lost custody/reentry in both directions, parking/volume fences and subsequent USB handoff. Existing assertions remain intact.

Before physical qualification, prepare an exact reviewed opt-in local diagnostic image and recovery preflight. Separately authorize installation/reset, attended low-volume synthetic-tone interruption/restart tests, any RX/microphone activation and any external measurement/recording. No token/cloud session is needed for the local codec diagnostic. Measure register/state traces, old-marker replay and interruption latency; hearing a stop alone is not a universal acoustic guarantee. Define bounded acceptance criteria and a supported recovery from partial failure before enabling physical capability. This source PR performs no device, serial, flash, microphone, live audio/session, enrollment/credential or security operation.


An optional [inert diagnostic collector](muse-quiesce-diagnostic.md) now privately captures this explicit operation’s result and historical binding flags. Formatting and recovery classification do no IO; no recovery action, automatic caller or physical success is added.
