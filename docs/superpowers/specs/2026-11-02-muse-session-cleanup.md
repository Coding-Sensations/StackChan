# Retained admitted Muse session composition

Intent: one serialized single-use owner transfers an unused exact Protocol/Clock admission, borrows existing codec/native authority, composes actual reviewed directions, and enforces audio checked stop/join/release before original SDK/socket retirement. Unknown audio or transport cleanup retains original owners without reconnect or write retry. Close request during callout revokes directions/review immediately and stops original-scope callbacks before any next operation; actual retirement waits for the outer operation.

UI borrows are bounded move-only RAII handles. The actual admission/review objects remain alive through transport closure until every original handle is released; handle destruction has no IO and cannot forge a join boolean. Destructor requires complete cleanup and zero borrows. Native UI must serialize callbacks, use Bridge only within the borrow lifetime and drain its callbacks before releasing it. This proves retention, not actual LVGL/widget/hardware acceptance. No new route/native grant/caller is registered.

End first revokes/stops audio, then asks the existing admission worker to cancel once under the original still-current scope/budget. Only ending transport ticks remain allowed. End during an in-flight scope call revokes that operation; uncertain transport closes rather than replaying. Pending/empty audio results are not fatal by themselves. No direction methods resume after end/close. Remote end confirmation comes only from actual Protocol.EndConfirmed, never a local stop/send.

Approaches: leave separate callers to order raw owners (lifetime gap); BooleanUIjoin callback (unverified acknowledgement); transfer admission and retain move-only UI borrows with actual joined owners (chosen). Reuse existing SDK/Worker/ReviewedDirectionOwner/Core/Clock, no researched alternate server has matching Noise/session/UI lifetime ownership; no copied vendor/unlicensed code. Native authority/admission UI/physical flush stay unavailable until separately implemented/validated. No device/live/credentials/security/merge; preserve other providers/layout/trust and frozen artifacts.
