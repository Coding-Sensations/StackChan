# Checked cold output-only retirement source

Implement a program-lifetime, explicitly obtained CoreS3 diagnostic instance. Obtaining it performs no IO. The one explicit initialization binds a caller-owned exact Muse lease before any SDK call and creates only a TX channel in READY, AW88298 control and checked mute/disable/readback. Never allocate/init/enable RX, instantiate ES7210, create input/output esp_codec_dev handles,  preload or play PCM. All I2S GPIO signals are forced unused; SDK STD init allocates internal DMA interrupt machinery and enables internal clocks, without a Core TX-sent callback or channel start. All PCM/enable/volume/USB/rebinding entrypoints on this instance refuse. Normal construction remains byte-for-byte unchanged except a cold destructor guard; Stock/Mira/USB retain normal paths.

Use pinned existing SDK factories/status APIs. Typed single-use initialization evidence preserves raw errors, null factory result, binding loss and amplifier evidence. Every attempted initialization failure retains original custody/resources and cannot retry. No automatic cleanup/deletion/recovery. Successful source-only absence of input is distinct from actual stop/close receipts. Checked TX info must show owned TX/STD, disabled and bounded nonzero DMA before retirement. Do not accept INVALID_STATE disable, mutate private driver structures or fabricate stopped/closed flags.

Existing checked quiesce/discard/release consume original-lease-bound never-created-input and never-opened-output evidence, and preserve one-attempt failure retention. Production PTT/physical flush stay false. No runtime caller/build option/image yet. No hardware, credentials, network, microphone or live session actions.

Approach decision: a separate retirement-only cold singleton avoids changing normal startup and avoids presenting an output-capable codec without a reviewed output consent contract. A normal constructor followed by stop violates no-microphone scope. Synthetic receipt flags and a dummy unavailable image are rejected.
