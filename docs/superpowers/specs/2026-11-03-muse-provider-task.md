A trusted native owner must supply the exact independently authorized VoiceAdmissionScope and an already initialized original CoreS3 codec; no grant, credential, codec initialization, remote identity or native actor attestation is invented. Current setup still only issues Pair/Chat scopes; the new trusted voice staging API is not a USB/BLE/network receiver.

Allocate large SDK/runtime work on heap inside a dedicated bounded-stack task. It creates/owns an independent LVGL surface, so provider app closure cannot free widget callback storage. Protocol IO stays outside checked UI mutex. Only a current original scope/foreground/reader may admit, and only actual reviewed native consent may prepare directions. No automatic capture/playback; hold/physicalflush remain unavailable.

A retained task lifecycle primitive owns factory/work through cleanup. Reaper also drains API references before releasing captured scope/custody and publishing slot cleanup. Reaper-creation failure retains the slot and is retryable cleanup only, never a repeat SDK Start. Existing provider onClose signals stop; worker-owned surface remains until checked cleanup, independent of provider parent.

Provider Settings may show Start prepared voice / Show voice review only for the matching staged state. Tile entry never starts a task. Lifetime snapshots are not recording/playback/connection-quality claims. Muse-off/voice-off/RAM0 are inert. Preserve other five identities, Stock/Mira/shared audio/USB, existing Pair/Chat, profile/config/trust/assets/partitions and frozen images. Tests use synthetic scopes/credentials and inert tasks/IO; actual hardware/native task/heap/live/recovery acceptance remains separate.
